# DYNOSTY

**웹 브라우저에서 즐기는 3D 생존·도시 경영 게임**입니다.
공룡과 주민이 살아가는 도시에서 자원을 관리하고, 발주·검수·배급 미션을 진행합니다.

화면·게임 계산·온라인 저장·서버 운영을 **이 레포 한 곳에서 관리**합니다.

> 현재는 개발 방향과 역할을 정리한 단계입니다. 아래 폴더와 기능은 앞으로 구현할 계획입니다.

## 누가 무엇을 만드나요?

팀은 총 3명이고, 그중 개발자는 2명입니다.

| 담당 | 맡은 일 |
| --- | --- |
| 기획·디자인 담당 | 게임 규칙과 미션 설계, 화면·시각 디자인 |
| 화면 개발 담당 | 3D 도시·공룡·카메라, 버튼·메뉴·관리 화면 구현 |
| 게임 로직·서버 개발 담당 | 게임 규칙을 코드로 구현, 계정·저장·DB·배포·서버 운영 |

기획·디자인 담당이 정한 규칙을 게임 로직 담당이 계산 코드로 만들고, 화면 담당이 그 결과를 보여줍니다.

## 코드는 어떻게 나누나요?

레포는 하나로 쓰고, 역할에 따라 폴더를 나눕니다.

```text
dynosty/
├─ apps/
│  ├─ web/             # 플레이어가 보고 조작하는 화면
│  └─ api/             # 계정·온라인 저장 요청을 처리하는 서버
├─ packages/
│  └─ game-core/       # 주민·재고·생산·미션을 계산하는 규칙
├─ infra/              # 배포·서버 설정·백업·복구 절차
└─ docs/               # 게임 설계와 팀 협업 문서
```

화면 담당은 주로 `apps/web`, 게임 로직·서버 담당은 `apps/api`·`packages/game-core`·`infra`를 관리합니다.
함께 바뀌는 화면·계산·저장 형식은 한 레포에서 맞춰 확인합니다. 웹과 API는 각각 배포할 수 있습니다.

## 어떤 기술을 쓰나요?

| 영역 | 기술 | 쉽게 말하면 |
| --- | --- | --- |
| 게임 화면 | Babylon.js + React | 3D 세상과 버튼·메뉴를 만듭니다. |
| 게임 계산 | TypeScript + Web Worker | 화면과 별도로 주민·자원·미션을 계산합니다. |
| 온라인 서버 | Node.js + Fastify, REST API | 로그인·저장·불러오기 요청을 처리합니다. |
| 데이터 보관 | PostgreSQL | 계정과 온라인 저장 기록을 보관합니다. |
| 서버 운영 | Hostinger VPS 후보 + HTTPS | 서버를 실행하고 안전한 통신을 연결합니다. |

TypeScript는 화면·게임 계산·서버에서 공통으로 사용하는 개발 언어입니다.

## 서로 어떻게 연결되나요?

```text
플레이어 PC / 브라우저
  Web: 화면 표시와 조작
    ↕ 조작 전달·계산 결과
  Game Core: Worker 안에서 게임 계산

  Web ↔ HTTPS ↔ API ↔ PostgreSQL
                  서버의 계정·온라인 저장

Infra: 웹·API 배포와 서버 운영 환경 관리
```

- 건설·발주 같은 조작은 **Core가 계산하고 Web이 결과를 보여줍니다.**
- 로그인·저장·불러오기는 **Web이 API에 요청하고, API가 DB를 사용합니다.**
- Core는 웹·API에서 필요한 규칙과 데이터 형식을 함께 사용하는 코드입니다. 별도 Core 서버는 띄우지 않습니다.
- 3D 화면과 평소 게임 계산은 플레이어 PC에서 실행하므로 별도 GPU 서버를 전제로 하지 않습니다.
- 경쟁 랭킹을 도입할 때는 제출 결과를 서버에서 검증해야 합니다.

## 무엇부터 만드나요?

1. **첫 화면:** 3D 에셋 불러오기, 도시 표시, 카메라 이동
2. **미션 1:** 자원 확인 → 발주 → 검수 → 배급 → 하루 정산
3. **저장:** 게임 저장·불러오기, 계정과 서버 연결
4. **성능 확인:** 주민 최대 56명·건물·날씨를 함께 실행해 측정

60FPS는 목표이며, Hostinger KVM 2는 초기 서버 후보입니다. 실제 성능과 부하를 측정한 뒤 구성을 조정합니다.
비밀번호·토큰·실제 사용자 데이터·백업 파일은 공개 레포에 올리지 않습니다.
