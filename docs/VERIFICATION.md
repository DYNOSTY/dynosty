# 개발 기반 검증 기록

검증일: 2026-11-13. 이 기록은 초기 개발 환경의 동작 확인이며 완성된 게임의 품질·성능 평가가 아닙니다.

| 범위                                          | 결과                                       |
| --------------------------------------------- | ------------------------------------------ |
| lockfile을 고정한 의존성 설치                 | 통과                                       |
| Biome 코드 검사·TypeScript 타입 검사          | 통과                                       |
| 코어 상태·잘못된 날짜·API 준비 상태 테스트    | 8개 통과                                   |
| Core·API·Web 빌드                             | 통과                                       |
| 실제 PostgreSQL 쿼리                          | 통과                                       |
| Playwright: 웹 프록시 → API → PostgreSQL      | 통과                                       |
| Playwright: 3D 표시·Worker 날짜 진행·API 응답 | 통과, 브라우저 예외 없음                   |
| 빌드한 Web과 API 실행                         | 3D·Worker·API·DB 연결 통과                 |
| `pnpm dev` 실행과 Ctrl+C 종료                 | 웹·API·코어 프로세스 시작·종료 확인        |
| 로컬 설정 재생성                              | 기존 값 유지, 파일 권한 제한·Git 제외 확인 |
| 실행 의존성 보안 권고 조회                    | 조회 시 알려진 취약점 없음                 |

브라우저 검사는 Linux Chromium의 소프트웨어 그래픽으로 실행했습니다.
실제 사용자 PC의 GPU·모바일·다른 브라우저와 56명 주민·날씨·건물을 함께 실행한 성능은 아직 검증하지 않았습니다.

Babylon.js 장면 청크가 압축 전 약 952KB여서 Vite의 500KB 크기 경고가 있습니다.
3D 코드는 첫 화면 코드와 분리해 지연 로딩합니다. 실제 게임 에셋과 화면이 추가되면 로딩 시간과 메모리를 다시 측정합니다.

로그인·게임 저장·랭킹·실제 미션·운영 배포는 아직 구현하지 않았습니다.
CI는 같은 코드 검사와 개발 서버 기반 브라우저·DB 검사를 수행하며, 실행 결과는 GitHub Actions에서 확인합니다.
