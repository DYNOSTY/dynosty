# 수동 BGM·음성 재생

화면의 **BGM과 음성**에서 각각 파일을 선택한 뒤 재생 버튼을 누릅니다. 선택한 파일은 브라우저 안에서만 사용하며 서버로 업로드하지 않습니다. 사건·미션·날씨에 따른 자동 재생 조건은 연결하지 않았습니다.

| 종류                | 동작                                                      |
| ------------------- | --------------------------------------------------------- |
| BGM                 | 선택한 파일을 반복 재생. 정지 버튼으로 처음 상태로 돌아감 |
| 음성                | 선택한 파일을 한 번 재생. 자연 종료 또는 정지 가능        |
| 함께 재생           | BGM과 음성을 동시에 재생할 수 있고 각각 정지 가능         |
| 같은 종류의 새 재생 | 이전 재생을 중지하고 새 파일을 처음부터 재생              |

설정의 **전체 음량·소리 끄기**는 확인음·BGM·음성의 공용 출력에 함께 적용됩니다. 음소거 중에도 사용자가 시작한 BGM·음성의 재생 시간은 흐르며, 음소거를 해제하면 현재 위치에서 들립니다. 설정 메뉴를 닫아도 BGM·음성은 계속 재생됩니다. 메뉴 닫기는 확인음만 중지합니다.

파일을 선택하는 것만으로 재생하지 않습니다. 새로고침 후에도 자동 재생하지 않으며 파일은 다시 선택해야 합니다. 음량·음소거 설정은 기존 로컬 설정에서 복원합니다. [음원 목록](AUDIO_CATALOG.md)에 등록하면 이름·종류·연결 파일명도 저장하지만, 파일 내용과 재생 위치는 저장하지 않습니다. 새로고침 후에는 파일을 다시 연결해야 합니다. 게임 저장 기록은 변경하지 않습니다.

## 연결과 수명 관리

- `AudioProvider.tsx`가 설정과 오디오 제어기를 화면 전체에 공유합니다. 설정 메뉴와 재생 패널이 별도 오디오 환경을 만들지 않습니다.
- `audio.ts`가 종류마다 HTMLAudioElement 하나와 연결 노드 하나를 재사용합니다. 두 채널 모두 같은 GainNode를 거칩니다.
- 사용자가 재생을 누를 때 AudioContext와 오디오 요소를 준비합니다. 브라우저 재생 정책을 우회하지 않습니다.
- 정지 시 재생을 멈추고 요소의 파일 주소를 비웁니다. 다시 재생하면 선택한 파일을 처음부터 사용합니다.
- 파일 교체 시 이전 재생을 멈춘 뒤 이전 Object URL을 해제합니다. 화면 종료 시 남은 파일 참조·오디오 요소·연결 노드·AudioContext를 정리합니다.
- 요청 번호로 정지·교체 뒤 도착한 이전 재생 응답과 오류를 무시합니다.

## 파일과 오류

음원 파일 선택을 지원하며 실제 재생 가능 형식은 브라우저의 코덱 지원에 따릅니다. 잘못된 파일 종류는 안내하고 이전 선택을 유지합니다. 손상·미지원 음원이나 재생 권한 거부는 안전한 메시지로 표시하며, 새 파일 선택이나 재생 버튼으로 다시 시도할 수 있습니다. 자동 재시도는 하지 않습니다.

이번 기능은 재생 기반입니다. 실제 게임 BGM·대사 파일의 배포, 사건별 우선순위·자동 전환·크로스페이드·음성 재생 중 BGM 감쇠는 아직 연결하지 않았습니다.

## 검증

`pnpm check`는 공용 출력 연결, 채널 분리, 요소 재사용, 중지 뒤 늦은 응답 무시, 오류와 종료 정리를 검사합니다. 단위 검사에는 가짜 오디오 장치를 사용합니다.

로컬 DB를 켜고 `pnpm test:e2e`를 실행하면 테스트에서 만든 PCM WAV를 실제 Chromium의 HTMLAudioElement·MediaElementAudioSourceNode로 재생합니다. 반복·동시 재생·음성 종료·개별 정지·파일 교체·출력 음량·음소거·기존 저장 보존·오류 후 재생을 확인합니다. 테스트 관찰 코드는 테스트에서만 주입합니다.

WAV 테스트 음원은 재생 경로를 검사하기 위한 소리이며 실제 BGM·대사 내용 검수나 물리 스피커의 청취 품질 검증이 아닙니다. 권한 거부는 오류 주입으로 검사합니다.
