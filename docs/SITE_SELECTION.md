# 조달 현장 선택과 작업

**마른 목재20 조달 체험하기 → 일손 배치·배급 체험하기**에서 검수대·격리품·배급소를 직접 누릅니다. 선택한 장소에 청록색 테두리가 생기고 오른쪽 현장 정보에 최신 수량·품질·담당·진행과 가능한 작업을 표시합니다. 작은 화면은 아래 정보로 이동하며 화면 아래의 같은 이름 선택 버튼을 키보드로도 사용할 수 있습니다.

| 현장   | 정보                                                          | 기존 작업 연결                                                 |
| ------ | ------------------------------------------------------------- | -------------------------------------------------------------- |
| 검수대 | 원납품/교환품 검사대기·합격 수령전 수량, 담당, 남은 검사 시간 | 원납품 검사 시작·정상분 수령, 교환품 재검수 시작·합격4 수령    |
| 격리품 | 젖은 목재4, 사용 불가 상태, 보완 진행·담당·교환 예약          | 보완 인원 배정/복귀, 공급처 교환 요청·출발 전 취소·회수 출발   |
| 배급소 | 요청 공개/기한·대기무리·준비량·담당                           | 빈 일손 배정, 보완 담당을 배급으로 재배치, 배급 담당 대기 복귀 |

검수대는 일손 체험에서 항상 보이며 검사할 물량이 없으면 상태와 이유를 표시합니다. 원납품을 내려놓은 뒤에는 수레와 검수대 양쪽에 같은 물량을 중복 표시하지 않습니다. 격리품은 앞쪽으로 옮겨 다른 물체에 가려지지 않게 했습니다. 배급소와 격리품의 위치 변경은 표시용이며 게임의 이동 시간이나 처리량을 바꾸지 않습니다.

## 선택과 입력

한 번에 하나의 장소 또는 기존 건물 예제만 선택합니다. 다른 장소를 누르면 테두리와 정보가 함께 바뀝니다. **빈 바닥 클릭** 또는 **현장 선택 해제**로 선택을 해제합니다. 마우스 드래그·휠·멀티터치는 기존 카메라 입력을 유지하며 카메라를 움직였다고 선택하지 않습니다.

격리품이 회수되거나 보완이 끝나 수량0이 되면 격리품은 숨기고 선택도 해제합니다. 검수대는 빈 상태에서도 장소가 남아 선택을 유지하고 정보를 갱신합니다. 기존 목재 체험·생존 예제로 나가면 현장 선택을 해제하며 일손 모드 밖에서는 현장 물체를 선택하지 않습니다. 기존 건물/주민 선택은 기존 예제에서 계속 동작합니다.

## 실제 조작과 일손

현장 버튼은 기존 코어 명령의 현재 조건을 검사해 사용할 수 없는 작업을 비활성화합니다. 실제 클릭은 기존 Worker 명령으로 보내며 계산·재고·결제·시간 처리를 별도로 만들지 않습니다. 선택과 미리보기는 명령 이력이나 게임 원장을 변경하지 않습니다. 같은 상태의 미리보기는 화면 재렌더링마다 반복하지 않도록 메모합니다.

운송·검수·교환 예약자는 배급소로 옮길 수 없습니다. 보완 담당을 배급으로 옮기면 같은 사람을 중복 배정하지 않고 기존 보완 진행량을 보존합니다. 다른 사람이 돌아와 보완2명이 되면 남은 시간부터 이어갑니다. 현장 선택을 바꾸거나 카메라를 움직여도 Worker와 게임 상태는 유지합니다. 기존 전체 조작 패널도 사용할 수 있습니다.

## 저장과 복원

현장 선택은 화면 상태이며 저장 데이터에 넣지 않습니다. 기존 일손 저장 v2와 v1 읽기 호환을 유지합니다. **불러오기 성공·새 체험 시작**은 선택을 해제합니다. 이후 장소를 다시 누르면 복원된 수량·담당·진행량으로 표시합니다. 저장 버튼을 눌렀다고 선택을 해제하거나 진행을 바꾸지 않습니다. 손상 저장의 불러오기 실패는 기존 선택·진행·저장 원문을 유지합니다.

기획·시나리오·영상과 게임 코어의 계산·저장 형식은 변경하지 않았습니다. 일손4명, 기존 보완·배급·교환 시간과 비용은 계속 체험용 개발값입니다. 새 품질 점수·반품 책임·위약금·공급 신뢰도·무작위 불량률·영양·기아 규칙은 추가하지 않습니다. 본편 미정 수치는 미정으로 유지합니다.

검증 기록은 `VERIFICATION.md`에 분리해 기록합니다. 실제 사용자 재미·난이도·실기기 GPU/휴대전화 성능은 별도 평가 대상입니다.
