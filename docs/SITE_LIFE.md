# 운송·주민 작업·첫 플레이 안내

일손 배치·배급 체험에 아래 표시를 추가했습니다. 기존 시나리오와 영상은 유지합니다.

- 운송: 원납품·불량품 회수·교환품 재납품을 이름과 적재 수량, 진행 막대로 구분합니다. 수레 경로와 결속띠가 보이고 이동량에 따라 바퀴가 회전합니다. 도착하면 적재는 사라지고 검수대에 기존 물량이 표시됩니다. 하역은 도착 시점에 완료되며 별도 대기 시간이나 명령은 없습니다.
- 주민: 보완 담당은 격리품 곁, 배급 담당은 실제 배급 준비대 주변, 검수 담당은 검수대 곁으로 이동합니다. 기존 배정에 따라 걷고, 자동 시간이 흐르는 작업 중에는 몸을 움직입니다. 인원이 부족하거나 작업 조건을 충족하지 못하면 대기 상태를 표시합니다. 자동 시간이 일시정지되면 작업 동작도 멈추며, 시간 진행 버튼은 그대로 사용할 수 있습니다. 자리로 이동하는 연출은 작업 계산을 지연시키지 않습니다.
- 안내: ‘지금 할 일’에서 목재의 다음 작업과 배급 준비를 나란히 안내합니다. 공급 A/B, 현장 보완/교환 분기와 검사·수령·배분·사용 확인을 기존 상태에 따라 설명합니다. 장소 보기 버튼은 기존 현장 선택·테두리·정보 패널을 사용합니다. 안내를 접어도 작업은 유지됩니다.

운송 진행과 다음 작업, 주민 담당은 Worker가 보내는 기존 상태에서 계산합니다. 새 저장 필드나 별도 진행 시계는 없습니다. 저장을 불러오면 해당 시점의 운송 단계·담당·작업 안내를 다시 표시합니다. 안내 접힘은 임시 화면 설정이며 새로고침 후에는 다시 펼쳐집니다. 수레와 주민의 짧은 보간·동작 위상은 저장하지 않습니다.

기존 체험용 A/B 운송 시간, 회수·재납품·재검수 시간, 보완 인원과 배급 준비량만 사용합니다. 본편 품질 점수·불량률·위약금·공급처 신뢰도·거리 비용·새 하역 시간은 확정하지 않았습니다. 기획 검토 문서 3개도 변경하지 않습니다.

표현의 구현·브라우저 동작 검증과 실제 사용자의 이해도·재미·실기기 성능 검증은 별개입니다. 검증 근거와 한계는 [검증 기록](VERIFICATION.md)에 남깁니다.
