# 현장 작업 진행 표시

마른 목재20 → 일손 배치·배급 체험에서 장소를 선택하지 않아도 화면 아래 카드3개에 검수대·격리품·배급소 상태, 진행량, 실제 담당 인원, 대기/중단 이유를 표시합니다. 장면의 번호1·2·3은 카드와 대응하며 카메라를 따라 이동합니다. 번호는 마우스/터치 입력을 가리지 않습니다. 물량이 없어 격리품이 숨겨져도 카드는 교환 처리 경과를 계속 보여줍니다. 카드의 작업 보기로 기존 현장 패널을 열 수 있습니다.

원납품 검사·교환품 재검수는 기존 검사분/총분, 현장 보완은 누적분/240분, 배급 준비는 누적 인·분/360인·분을 표시합니다. 교환 수령은 정상 교환품 수령 개수/4개이며 운송률이나 품질 점수가 아닙니다. 검사 시작·수령 확인 대기, 원납품/교환품 도착 대기, 배급 요청 공개 전, 담당 부족, 자동 시간 일시정지를 구분합니다. 보완 인원이 줄어 코어가 received 상태로 전환해도 진행량과 부족 이유를 표시합니다. 전진 버튼은 기존처럼 다음 사건 경계까지만 진행합니다. 예상 완료시간이나 새 처리량은 만들지 않습니다.

실제 검사·보완·배급·재검수·교환 수령 전이가 발생하면 최근4개 완료 알림을 표시합니다. 알림은 실제 게임 시간이며 닫을 수 있습니다. 실시간 tick·수동 시간 진행 모두 같은 상태로 표시합니다. 초기 시작·새 체험·성공한 불러오기는 알림을 비우고 복원된 상태를 기준으로 삼으며, 이미 완료된 저장을 불러왔다고 완료를 다시 알리지 않습니다. 실패한 불러오기는 기존 상태·알림·저장 원문을 유지합니다. 알림과 현장 번호/선택은 저장 데이터에 추가하지 않습니다.

기존 LaborState와 코어 명령/계산/저장 v1·v2를 유지합니다. Worker 상태 응답의 reset 표식만 초기/복원/재시작을 구분하는 화면 메타데이터로 추가했습니다. React는 안정된 상태 수신 callback을 유지하고 진행 카드는 상태 변경시에만 파생합니다. 현장 번호는 씬 투영을 사용하며 React를 프레임마다 갱신하지 않고 좌표가 바뀐 경우에만 DOM 위치를 갱신합니다. 모드 종료와 씬 폐기에서 참조를 정리합니다.

모든 시간·수량·인원은 기존 체험용 개발값입니다. 기존 시나리오·영상은 유지합니다. 본편 품질 점수·불량률·위약금·공급처 신뢰도·영양·기아 규칙은 미정이며 추가하지 않습니다. 기획 검토 문서3개는 변경/커밋 대상에서 제외합니다. 실제 재미·난이도·실기기 및 다른 브라우저 성능은 별도 관찰 대상입니다.
