# 건물·주민 예제 선택

중앙 3D 장면의 건물 또는 주민을 클릭하면 대상에 하늘색 테두리가 생기고 **선택 정보** 패널이 열립니다. 빈 바닥이나 빈 배경을 클릭하면 선택을 해제합니다. 카메라를 드래그해 회전하거나 우클릭하는 것은 선택으로 처리하지 않습니다.

캔버스 아래 **건물 예제 선택·주민 예제 선택** 버튼으로도 같은 대상을 선택할 수 있습니다. 키보드로 버튼에 초점을 맞추고 Enter를 누릅니다. 정보 패널의 **선택 해제** 버튼은 선택을 지우고 캔버스로 초점을 돌려줍니다. 좁은 화면에서는 정보 패널이 장면 아래에 표시됩니다.

## 표시 정보와 보존 범위

현재 예제의 종류·표시 상태·좌표만 표시합니다.

| 대상      | 표시 상태                                        | 좌표                |
| --------- | ------------------------------------------------ | ------------------- |
| 건물 예제 | 기존 `highlighted` 값에 따른 기본 외형·강조 외형 | 기존 위치의 X, Y, Z |
| 주민 예제 | 기존 `motion` 값에 따른 대기 표시·걷기 표시      | 기존 위치의 X, Y, Z |

좌표의 실제 거리 단위·이동 속도·시간 규칙은 정하지 않습니다. 걷기 표시는 기존 전달 규격의 표시 값이며 실제 보행 시뮬레이션이나 새로운 애니메이션을 추가한 것이 아닙니다. 선택 테두리는 기존 건물의 노란 강조 외형과 별개입니다.

선택은 화면 상태입니다. 날짜·예제 상태·저장 내용·서버 데이터를 수정하지 않고 파일에 저장하지 않습니다. 새로고침하면 선택이 해제됩니다. 저장·설정·개발 도구 메뉴를 여닫아도 선택을 유지하며, 예제 변경과 저장 불러오기로 장면을 갱신하면 같은 대상의 최신 정보를 보여줍니다.

선택한 대상이 삭제·숨김 처리되거나 같은 식별값의 종류가 바뀌면 선택을 해제합니다. 지원하지 않는 표시 정보가 들어와 검증에 실패하면 기존 선택·장면을 보존합니다.

## 구현 경계

- `scene-entities.ts`가 표시 객체와 선택 식별값을 관리하고 한 대상에만 Babylon의 outline을 적용합니다. 기존 색상·표시 규격은 바꾸지 않습니다.
- `scene-input.ts`가 이동 6px 이내의 단일 왼쪽 클릭을 전달합니다. 드래그·다중 터치·취소·영역 밖 해제를 제외하고, `scene.ts`가 실제 picking 결과를 선택으로 전달합니다. 빠른 연속 클릭도 간격 제한 없이 처리합니다.
- `App.tsx`는 선택 식별값과 마지막으로 장면에 적용한 스냅샷을 함께 사용하고, `SelectionPanel.tsx`는 해당 값만 표시합니다.
- 종료 시 pointer 이벤트 리스너·장면·객체를 정리하며 UI를 종료하는 동안 선택 콜백을 재호출하지 않습니다.

자원·주민 능력치·건설 비용·미션 조건·사건별 재생 조건은 추가하지 않았습니다. Core·Worker·저장 규격과 기획 검토 문서는 변경하지 않습니다.
