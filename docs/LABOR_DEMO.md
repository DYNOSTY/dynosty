# 일손 배치와 배급소 혼잡 해소 체험

첫 화면에서 **마른 목재20 조달 체험하기 → 일손 배치·배급 체험하기**를 누릅니다. 기존 목재 체험과 생존 예제는 돌아가기 버튼으로 전환할 수 있습니다. 시나리오·영상·본편 게임 데이터는 유지합니다.

일손 1~4는 각자 하나의 작업만 맡습니다. 약정 시 빈 일손 한 명을 운송·검사에 예약하며 검사가 끝날 때까지 다른 작업으로 보낼 수 없습니다. 다른 작업은 각 행의 목적지를 고른 뒤 배정 또는 재배치를 누릅니다. 이미 배정된 사람을 다시 배정하는 명령, 오래된 이전 담당 정보를 사용한 재배치, 같은 명령의 중복 처리는 코어에서 차단합니다.

목재 보완은 두 명이 모였을 때만 진행합니다. 한 명을 옮기면 진행한 시간을 보존한 채 멈추며 두 명이 다시 모이면 남은 시간부터 진행합니다. 배급 준비는 인원이 늘수록 작업량이 빨리 쌓입니다. 두 작업이 같은 시간에 진행되므로 한 시간을 진행하면 양쪽에 각각 반영됩니다. 다음 사건 버튼은 요청 공개·도착·검사·작업 완료 중 가장 이른 시점에 멈춥니다.

| 체험 경로                          | 목재 결과                                               | 배급 준비 결과             |
| ---------------------------------- | ------------------------------------------------------- | -------------------------- |
| A: 8시간에 보완2명·배급2명         | 12시간 완료, 철재4 남음                                 | 11시간 완료, 60분 지연     |
| A: 9시간에 보완1명을 배급으로 옮김 | 60분 진행을 보존. 배급 완료 뒤 복귀하면 13시간20분 완료 | 10시간20분 완료, 20분 지연 |
| B: 8시간에 운송1명·배급3명         | 10시간 도착,12시간 검사·사용 완료, 철재2 남음           | 10시간 완료, 기한 충족     |

배급소 옆 주황색 표시는 대기3무리입니다. 작업량120마다 한 무리씩 사라집니다. 네 일손은 작업 위치로 이동하며 목재 사용 후에는 기존 지붕 보수 표시가 적용됩니다. 이동 애니메이션은 시각 표시이며 추가 게임 시간을 차감하지 않습니다.

## 저장과 복원

확장 체험은 전용 Worker와 `dynosty.labor.saves` 로컬 묶음을 사용합니다. `일손 체험 저장`은 현재 상태를 최근 저장으로, 기존 최근 저장을 이전 저장으로 보관합니다. 새로고침 후 같은 체험으로 들어가 `일손 체험 불러오기`를 누르면 시간·담당자·양쪽 진행량·재개할 남은 시간·대기 줄·철재·목재가 일시정지 상태로 복원됩니다. 오프라인 시간은 추가하지 않습니다.

기존 `dynosty.timber.saves`와 `dynosty.play.saves`는 읽거나 변경하지 않습니다. 기존 저장을 확장 체험으로 자동 변환하지 않으며 기존 모드에서 계속 사용할 수 있습니다. 손상 JSON·미지원 형식·중복 일손·일치하지 않는 작업 종료 시각·손상된 이전 저장은 원문을 보존하고 로드/덮어쓰기를 거부합니다. 저장 공간 부족도 단일 쓰기 실패로 처리해 최근·이전 묶음과 현재 진행을 유지합니다. 체험 재시작은 저장을 지우지 않습니다.

## 체험 전용 수치와 미정 사항

| 항목                  | 이번 체험의 개발용 값                   |
| --------------------- | --------------------------------------- |
| 공유 일손             | 4명                                     |
| 배급 준비 공개 / 기한 | 경과8시간 /10시간                       |
| 배급 준비 작업량      | 360인·분: 3명×120분,2명×180분,1명×360분 |
| 혼잡 표시             | 3무리,120인·분마다 한 무리 해소         |
| 목재 보완             | 2명으로 활성240분, 중단 시 보존         |
| 작업 전환 이동 시간   | 게임 시간0분, 화면 위치만 보간          |

이는 최종 기획 확정값이 아닙니다. 기존 목재 제안 A/B의 비용·도착·검사·기한 값은 그대로 재사용합니다. 배급 준비는 혼잡 해소 작업이며 음식360인분을 공급한다는 뜻이 아닙니다. 식량 소비·영양·기아·사망·본편 배급 간격·시간 배율·사건별 영상과 자동 재생 조건은 추가하거나 변경하지 않습니다.

## 검증 범위

공용 계산의 동시 진행·중복/오래된 배정 방지·예약·재개·동시 사건·저장 형식과 로컬 최근/이전 보존을 검사합니다. 실제 Chromium에서 UI→Worker→코어→로컬 저장→재로드→3D 반영까지 확인하고, 기존 API·DB·저장·미디어 기능을 회귀 검사합니다. 시연은 실제 마우스 입력을 녹화하며 게임 상태를 주입하지 않습니다.

실제 사용자의 재미·난이도 평가, 실기기 GPU/휴대전화 및 다른 브라우저 성능은 이번 검증 범위 밖입니다. 기존 3D 청크 크기 경고는 남아 있습니다. 결과와 실패 이력은 `VERIFICATION.md`에 기록합니다.

저장 검증은 경과 시간상 불가능한 배급·보완 진행량도 거부합니다. 중단한 작업의 유효한 진행량은 그대로 복원합니다. 정지한 일손은 같은 좌표를 매 프레임 재적용하지 않으며 모델 애니메이션과 배치 변경 시 이동은 계속 표시합니다.
