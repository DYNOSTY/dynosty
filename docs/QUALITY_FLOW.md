# 조달·품질 흐름과 공급 비교

일손 배치·배급 체험에서 목재의 운송 중·검사 대기·합격 수령 전·격리·사용 가능·배분·사용 확인 수량을 구분합니다. 원납품 출발 전 실제 물량은0이며, 출발하면 운송20, 도착하면 검사대기20, A 검사 후에는 합격16과 격리4로 이동합니다. 교환 미해결4는 운송·검사·합격 수령 전으로 이동하고 원래 격리 위치에서 동시에 계산하지 않습니다. 보완/교환 수령 후에는 정상 재고로 옮겨지고 배분·사용 시 각각 다음 위치로 이동합니다. 기존 수량 패널도 같은 표시 기준을 사용합니다.

회색은 검사 대기, 황금색은 정상 목재(검수대에서는 수령 전), 파란색은 격리, 주황색은 배분입니다. 정상 보관 더미와 배분 더미는 별도 위치에 표시합니다. 사용 확인된20개는 더미에서 사라지고 기존 지붕에 반영됩니다. 더미는 수량을 비율로 표시하는 개발 모델이며 한 상자가 목재 한 개를 뜻하지 않습니다. 현장 선택과 기존 운송/일손 이동을 유지하고 새 운송 시간이나 재고를 추가하지 않습니다.

공급 제안 A/B의 철재4/6, 운송6/10시간, 검사2시간, 고정 정상16/20·젖은4/0 조건을 나란히 비교합니다. 이는 기존 체험 조건이며 무작위 품질 확률이나 본편 보증이 아닙니다. 선택한 제안은 약정 뒤에도 비교할 수 있지만 변경 버튼은 비활성화합니다. 실제 원납품 결과는 검사를 마친 뒤에만 표시합니다.

처리 결과표는 최초 원납품 검사 결과, 보완 회복량, 교환품 수령량과 미수령량, 현재 격리·사용 가능·배분·사용 물량, 실제 철재 사용·별도 예약·잔여·가용 철재를 보여줍니다. 최초 검사16/4는 이후 보완되더라도 최초 결과로 유지합니다. 보완/교환4를 물량 합계에 다시 더하지 않습니다. 예약 철재는 실제 비용에 더하지 않고 가용 철재에서만 차감합니다. 모든 표와 장면은 현재 LaborState에서 파생하여 저장 v1/v2 복원 시 일치하며 새 저장 필드는 없습니다.

기존 체험용 개발값과 코어 계산을 그대로 사용합니다. 본편 품질 점수·무작위 불량률·공급처 신뢰도·위약금·책임·영양·기아는 계속 미정입니다. 기존 시나리오·영상과 기획 검토3개는 보존합니다. 실제 사람의 재미/이해도·실기기와 다른 브라우저 성능은 자동 검사와 별개로 관찰해야 합니다.
