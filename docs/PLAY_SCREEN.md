# 플레이 화면 골격

첫 화면에서 3D 예제 장면을 중앙에 크게 표시합니다. 상단에는 게임 날짜, 장면 준비 상태와 **저장·설정·개발 도구** 버튼이 있습니다. 현재 장면은 기본 도형으로 만든 개발 예제이며, 자원·주민·미션 규칙이나 실제 게임 아트는 추가하지 않았습니다.

| 메뉴      | 내용                                                                      |
| --------- | ------------------------------------------------------------------------- |
| 저장      | 최근·직전 예제 저장과 불러오기, 저장 파일 내보내기·가져오기               |
| 설정      | 기존 음량·음소거 설정 모달                                                |
| 개발 도구 | 서버·3D 연결 상태, 하루 진행·3D 예제 변경, 수동 BGM·음성·영상과 음원 목록 |

저장·개발 도구는 상단 버튼으로 각각 여닫습니다. 두 패널을 함께 열 수도 있습니다. 넓은 화면에서는 장면 오른쪽에, 좁은 화면에서는 장면 아래에 표시합니다. 패널의 **닫기**를 누르면 해당 상단 버튼으로 키보드 초점이 돌아갑니다. 메뉴 버튼의 펼침 상태와 연결된 패널을 보조 기술에 제공합니다. 설정은 기존처럼 Escape로 닫을 수 있습니다.

패널을 닫는 것은 표시만 접는 동작입니다. Worker·3D 장면을 다시 만들거나 날짜를 바꾸지 않고, 선택한 파일·저장 파일 미리보기·미디어 재생 상태를 유지합니다. 음원을 멈추려면 개발 도구의 정지 버튼을 사용합니다. 패널이 열려 장면 폭이 바뀌면 기존 ResizeObserver가 렌더링 크기를 맞춥니다.

새로고침하면 저장·개발 패널은 다시 접힌 상태로 시작합니다. 게임 상태·음량·파일 재연결·저장 보존 규칙은 각각 [로컬 저장](LOCAL_SAVE.md), [설정](SETTINGS.md), [음원 목록](AUDIO_CATALOG.md)을 따릅니다. 패널을 열었다는 이유만으로 게임 저장이나 음량 설정을 수정하지 않습니다.

이번 작업은 화면 배치와 탐색 경로 변경입니다. 시간 진행 방식·미션 조건·주민 계산·자동 미디어 재생 규칙은 정하지 않았습니다.
