# 플레이 화면

상단 자원 막대와 하단 명령 콘솔 사이에 박찬님의 겨울 섬·GLB 마을을 표시합니다. 생존 상태는 주민60명·자원7종·게임 시간과 시작/일시정지·1일 진행·새 게임 조작으로 확인합니다. 수치와 계산은 [승인 개발 기준](APPROVED_BASELINE.md)을 따릅니다.

| 메뉴      | 내용                                                                                |
| --------- | ----------------------------------------------------------------------------------- |
| 조달      | 목재 체험 → 일손 배치·배급 체험, 검수·격리·배급 현장 선택과 기존 작업               |
| 저장      | 생존 게임 최근·직전 저장과 불러오기                                                 |
| 설정      | 음량·음소거와 확인음                                                                |
| 개발 도구 | 서버·3D 연결 상태, 예제 하루 진행·모델 전환, 예제 저장·파일·BGM·음성·영상·음원 목록 |

저장·개발 도구·정찰 창은 한 번에 하나를 엽니다. 닫기 단추나 Escape로 닫고, 창 밖을 눌러서도 닫을 수 있습니다. 저장·개발 도구의 닫기를 사용하면 해당 메뉴로 키보드 초점이 돌아옵니다. 모바일에서는 사용 가능한 명령과 개발 도구를 하단 고정 바에서 열고 창 내부를 스크롤합니다.

조달 체험에서는 넓은 화면의 왼쪽 현장과 오른쪽 작업 패널을 함께 조작합니다. 현장 클릭을 막는 배경막을 사용하지 않습니다. 작은 화면에서는 현장과 작업 패널을 세로로 배치합니다. 다음 작업 안내·물량 흐름·담당 표지·완료 알림·장소 보기와 기본 시점 복귀를 유지합니다.

중앙의 대표 건물·주민을 누르면 [선택 정보](SCENE_SELECTION.md)와 하늘색 테두리를 표시합니다. 빈 바닥이나 선택 해제로 해제하고, 대상 선택 버튼으로 키보드 조작도 할 수 있습니다. 마을 시점은 회전·확대·WASD 이동, 조달 현장은 장소별 초점 이동을 지원합니다.

정찰의 거점·정찰대·발견 표시는 화면 시안입니다. 인원·식량에 반영하지 않고 게임 저장에 포함하지 않습니다. 새 게임과 성공적인 게임 불러오기는 정찰 표시도 초기화합니다.

창을 접어도 Worker·3D 캔버스를 다시 만들지 않고 선택한 파일·저장 미리보기·미디어 재생을 유지합니다. 음원을 멈추려면 개발 도구의 정지 버튼을 사용합니다. 저장·복원 규칙은 [로컬 저장](LOCAL_SAVE.md), [설정](SETTINGS.md), [음원 목록](AUDIO_CATALOG.md)을 따릅니다.

소프트웨어 그래픽 환경에서는 마을의 3D 해상도를 조정하고 대체 지도를 표시합니다. 조달 현장은 선택 테두리를 유지하도록 원래 해상도를 사용합니다. 원본 GLB·UI 이미지와 게임 상태는 유지합니다. 실제 검사 범위와 한계는 [검증 기록](VERIFICATION.md)을 확인하세요.
