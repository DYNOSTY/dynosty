# 설정 메뉴와 음량

첫 화면의 **설정** 버튼을 누르면 메뉴가 열립니다. **전체 음량**은 0~100%, **소리 끄기**는 음소거입니다. 음량은 방향키·Home·End로도 조절할 수 있습니다. **설정 닫기** 또는 Esc로 닫으면 처음 버튼으로 초점이 돌아옵니다.

설정은 변경 즉시 현재 실행에 적용하고 이 브라우저에 저장합니다. 다음 새로고침 때도 음량과 음소거를 복원합니다. 처음 사용하는 경우 기본값은 **50%, 음소거 해제**입니다. 이는 사용 환경 설정이며 게임 시간·자원·주민·미션 규칙과 관계없습니다. 설정 메뉴를 열어도 게임 계산에 일시정지 명령을 보내지 않습니다.

## 실제 소리 확인

**확인음 듣기**를 눌러 짧은 소리로 음량을 확인합니다. 현재는 실제 BGM·음성 파일 대신 약 0.45초의 확인음을 생성합니다. 페이지 시작이나 설정 복원만으로 소리를 재생하지 않으며, 음소거 또는 0%에서는 확인음 버튼을 사용할 수 없습니다.

`audio.ts`에서 Web Audio 출력 음량을 관리합니다. 전체 음량을 0~1 값으로 변환하고 음소거 시 출력값을 0으로 적용합니다. 확인음은 이 출력 노드를 거치며, 메뉴를 닫으면 확인음을 중지합니다. 화면 종료 시 음원 노드와 오디오 실행 환경을 정리합니다. 향후 실제 BGM·음성을 추가할 때도 이 공용 출력에 연결해야 합니다. 이번에 실제 미디어 파일 연결이나 사건별 음악 선택은 구현하지 않았습니다.

## 설정 저장과 오류 처리

- 키: `dynosty.settings`
- 형식: `{ settingsVersion: 1, masterVolume: 50, muted: false }`
- 게임 저장 키 `dynosty.example.saves`와 분리하며 해당 기록을 읽거나 쓰지 않습니다.
- 정수 음량 0~100, 음소거의 참/거짓, 지원 버전을 확인한 뒤 사용합니다.
- 손상·미지원 설정이나 접근 오류가 있으면 기본값과 안내를 표시합니다. 읽기만으로 저장된 원문을 덮어쓰지 않습니다.
- 사용자가 직접 설정을 바꾸면 새 값을 저장합니다. 따라서 손상된 설정도 명시적인 변경 후에는 정상 설정으로 교체할 수 있습니다.
- 쓰기 실패 시 현재 실행에는 변경을 적용하지만 저장 실패를 안내합니다. 단일 항목 쓰기가 실패하면 이전에 저장된 설정은 유지되고, 새로고침 후에는 그 값으로 돌아갑니다.
- 같은 브라우저·같은 사이트 주소의 로컬 설정입니다. 기기 간 동기화나 다중 탭 변경 조정 기능은 포함하지 않습니다.

## 검증 방법과 한계

`pnpm check`는 설정 형식·기본값·실패 시 기존 기록 보존과 오디오 연결·음소거·종료 정리를 검사합니다. 오디오 단위 검사에는 가짜 오디오 장치를 사용합니다.

로컬 DB를 켠 뒤 `pnpm test:e2e`로 메뉴의 키보드 조작·닫기·초점 복귀, 설정 저장과 새로고침 복원, 게임 저장과의 분리, 손상 설정·쓰기 실패·오디오 사용 불가 처리를 확인합니다. 실제 Chromium의 AudioContext와 출력 GainNode를 관찰해 저장된 음량과 음소거가 적용되는지 검사합니다. 테스트 관찰 정보는 테스트에서만 주입하며 제품 코드의 전역 객체에 넣지 않습니다.

쓰기 실패는 `QuotaExceededError`를 주입하며 실제 저장 공간을 가득 채우지 않습니다. 실제 스피커에서 들리는 크기·음질이나 여러 기기·브라우저의 청취 품질을 검증하는 검사는 아닙니다.
