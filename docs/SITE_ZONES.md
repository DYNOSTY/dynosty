# 조달 현장 구역과 목재 묶음

일손 배치·배급 체험에서 검수①·격리②·정상 보관◇·배분▧ 구역을 바닥 표시와 짧은 글자 표식으로 구분합니다. 배급소③ 표식은 기존대로 유지합니다. 검수는 평행 표시, 격리는 X와 뒤쪽 울타리, 정상 보관은 선반 프레임, 배분은 사선 표시를 사용합니다. 화면의 구역 안내는 색상 없이도 같은 기호와 이름으로 읽을 수 있습니다. 물량이 0이어도 구역과 표지는 남고 더미만 숨깁니다. 카메라 밖의 표식은 숨기며 회전·확대로 다시 볼 수 있습니다.

기존 목재 더미는 받침 위 판재와 결속띠가 있는 묶음으로 표현합니다. 수량에 따라 기존 더미의 폭이 변하며 판재 수는 게임 수량을 뜻하지 않습니다. 검수대의 미검사 목재는 회색, 확인된 정상 묶음은 목재색, 격리는 어두운 묶음과X구역, 배분은 주황 받침과 사선 구역으로 구분합니다. 실제 수량은 기존 물량 흐름/결과표를 기준으로 읽습니다. 새로운 품질 점수·용량·거리 비용·충돌·이동 시간 규칙은 없습니다.

검수대·격리품은 판재나 결속띠를 눌러도 같은 현장 정보와 테두리를 표시합니다. 빈 바닥은 선택 해제하며 구역 바닥·울타리·표지 기둥은 클릭을 가리지 않습니다. 기존 건물/주민·배급소 선택과 카메라 조작을 유지합니다. 수량이 없어 선택할 수 없는 장소에도 구역 표지는 남습니다. 저장에는 표시 필드를 추가하지 않고 복원한 상태의 수량·담당·진행과 같은 모습으로 표시합니다. 모드 종료 시 장식을 숨기고 기존 목재 예제의 상자 높이를 복원합니다.

같은 재질의 고정 장식은 합치고 판재/띠는 묶음별로 합쳐 그리기 객체 수를 줄였습니다. 선택과 테두리는 묶음의 자식 메시까지 매핑합니다. 반복 상태 갱신에서 객체가 늘어나지 않고 씬 폐기 시 표시 자원을 정리합니다. 이는 표시 최적화이며 실제 기기 FPS나 재미 개선 측정으로 해석하지 않습니다.

기존 코어·저장 v1/v2·개발 수치·시나리오·영상은 유지합니다. 본편 품질 점수·불량률·위약금·공급처 신뢰도와 영양/기아는 계속 미정입니다. 기획 검토 3개는 변경 대상에서 제외합니다.
