# 첫 플레이 점검·장소 이동·역할 표지

기존 일손 배치 체험의 A 현장 보완·A 공급처 교환·B 정상 납품 경로를 대상으로 화면을 점검했습니다. 실제 UI 자동 조작과 화면 검토이며, 처음 보는 사람의 이해도나 재미를 측정한 결과는 아닙니다.

확인한 불편은 장소를 골라도 카메라가 그대로인 점, 안내에서 공급 선택·약정·배분·사용 버튼을 다시 찾아야 하는 점, 주민별 역할과 수레 방향을 장면에서 읽기 어려운 점입니다.

- ‘작업 장소 보기’와 현장 진행 카드의 ‘작업 보기’는 선택·테두리·정보 패널을 열면서 카메라를 해당 장소로 옮깁니다. 캔버스도 화면에 들어오고 키보드 포커스를 받습니다. 대상이 없는 격리품은 이동하지 않습니다. 실제 장면 클릭과 ‘대상 선택’ 버튼은 선택만 하므로 카메라가 갑자기 움직이지 않습니다.
- 장소를 새로 선택하면 데스크톱의 오른쪽 패널은 정보 제목이 보이도록 내부 스크롤을 정리합니다. 모바일에서는 정보 패널로 전체 페이지를 강제로 이동시키지 않아 선택한 장면을 볼 수 있습니다.
- ‘기본 시점’은 전체 현장으로 돌아옵니다. 현장 체험을 나갈 때도 기본 시점으로 복귀합니다. 회전·줌 관성을 정리해 직전 드래그가 장소 이동을 덮어쓰지 않습니다.
- ‘목재 다음 조작으로 이동’은 현재 가능한 공급 비교·약정·출발·배분·사용 조작으로 스크롤과 포커스를 옮깁니다. 불량품 처리 중에도 정상 물량이 있으면 ‘정상 목재 배분으로 이동’을 보여줍니다. 링크는 조작 위치로 이동하며 계약·배분·사용을 대신 실행하지 않습니다.
- 주민 머리 위에는 번호와 역할을 표시합니다. ○ 대기, ↔ 운송·검사, ⇄ 교환·재검수, ＋ 보완, ▰ 배급을 테두리 색과 함께 사용합니다. 색을 보지 않아도 역할을 읽을 수 있으며 화면의 주민 담당 목록을 함께 제공합니다.
- 수레는 → 원납품/교환품 재납품, ← 불량품 회수와 적재 수량을 표시합니다. 도착 이후에는 운송 표지를 숨겨 검수대 재고와 구분합니다. 검수 표지에는 ≡, 격리에는 ×를 더해 기존 바닥 무늬와 연결합니다.
- 가까운 표지는 화면 안의 빈 세로 위치로 배치하고, 원래 위치에서 떨어진 경우 연결선을 그립니다. 놓을 공간이 없거나 카메라 밖이면 숨기며 다시 공간이 생기면 표시합니다. 상세 담당·수량은 기존 화면 목록에서 계속 확인할 수 있습니다. 표지 크기는 글자/화면 폭 변경 시 측정하고 프레임별 동작은 Babylon 투영과 DOM 위치 갱신에 한정합니다.

이동·줌·표지 배치는 표시 전용이며 저장하지 않습니다. 기존 상태를 불러오면 담당·물량에서 표지를 다시 계산합니다. 게임 시간·인원·재고·비용·저장 형식·시나리오·영상과 기존 체험용 개발값은 유지합니다. 품질 점수·불량률·위약금·공급처 신뢰도 등 미정 규칙과 기획 검토 문서3개는 변경하지 않습니다.
