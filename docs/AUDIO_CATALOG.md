# BGM·음성 음원 목록

상단 **개발 도구**에서 음원 목록을 관리합니다. 패널을 접어도 현재 파일 연결과 재생은 유지됩니다.

**BGM과 음성** 패널에서 파일에 이름을 붙이고 종류별 목록으로 관리합니다. 재생은 사용자가 버튼을 눌러 시작합니다. 사건별 자동 재생·자동 전환이나 미확정 기획 규칙은 연결하지 않습니다.

## 사용 방법

1. BGM 또는 음성에서 **파일 직접 선택**을 선택하고 파일을 고릅니다.
2. 알아보기 쉬운 이름을 입력한 뒤 **목록 추가**를 누릅니다. 파일 없이 이름부터 등록할 수도 있습니다.
3. 목록에서 음원을 선택하고 **재생**을 누릅니다. 같은 화면을 유지하는 동안 등록한 여러 파일을 다시 고르지 않고 전환할 수 있습니다.
4. 선택한 항목의 이름을 수정하고 **이름 변경**을 누르면 재생을 유지하면서 이름만 바뀝니다. 파일 입력에서 다른 파일을 고르면 연결을 교체하고 이전 재생을 정지합니다.
5. **목록에서 제거**는 선택한 항목과 브라우저의 파일 참조만 제거하고 해당 채널을 정지합니다. 다른 채널의 재생과 디스크의 원본 파일은 유지됩니다.

이름은 앞뒤 공백을 제외한 1~80자입니다. 같은 종류 안에서는 대소문자·한글 정규화가 다른 같은 이름도 중복으로 처리합니다. BGM과 음성은 같은 이름을 사용할 수 있습니다. 목록은 최대 500개입니다.

## 새로고침과 보존 범위

이름·종류·연결 파일명은 브라우저 로컬 저장소에 남습니다. **파일 내용과 파일 접근 권한은 저장하지 않으므로 새로고침 후에는 목록에서 항목을 선택하고 파일을 다시 연결해야 합니다.** 연결 전에는 재생 버튼을 사용할 수 없고, 파일명으로 자동 탐색하거나 같은 파일이라고 추정하지 않습니다. 새 파일을 연결하면 기존 항목의 식별값과 이름을 유지합니다.

파일은 서버에 업로드하지 않습니다. 파일 선택·목록 선택·복원으로 자동 재생하지 않습니다. 기존 전체 음량·음소거 설정을 그대로 적용하며, 음원 목록은 게임 저장·설정과 별도입니다. 게임 저장 파일 내보내기·가져오기에 음원 목록이나 파일은 포함되지 않습니다. 브라우저 데이터를 지우면 목록도 사라집니다.

## 저장과 오류 처리

`audio-catalog.ts`가 `dynosty.audio.catalog`에 다음 형식의 메타데이터를 저장합니다. 브라우저 전용 형식이며 게임 상태·Worker 전달 규격을 변경하지 않습니다.

```json
{
  "catalogVersion": 1,
  "entries": [
    {
      "id": "고유 식별값",
      "kind": "bgm",
      "name": "아침",
      "fileName": "morning.wav"
    }
  ]
}
```

`kind`는 `bgm` 또는 `voice`이고 미연결 항목의 `fileName`은 `null`입니다. 파일 내용·로컬 경로·Blob URL·재생 위치는 기록하지 않습니다. 연결한 `File`은 메모리에 보관하며 현재 선택의 Object URL만 만들고, 전환·교체·제거·화면 종료 때 해제합니다.

새 목록과 기존 저장을 검증한 뒤 `setItem` 한 번으로 저장합니다. 저장 공간 부족·접근 거부·잘못된 이름·중복에서 실패하면 기존 목록을 유지합니다. 파일 연결 교체도 메타데이터 저장이 성공한 뒤에 적용하므로 실패 시 이전 파일 연결과 재생을 보존합니다. 손상되거나 지원하지 않는 버전의 기존 기록은 덮어쓰지 않고 안내하며 **파일 직접 선택** 재생은 사용할 수 있습니다. 자동 초기화는 하지 않습니다.

재생 가능 형식·브라우저 권한·개별 정지·음량 동작은 [수동 BGM·음성 재생](MEDIA_AUDIO.md)을 따릅니다. 실제 게임 음원 배포나 사건별 연결은 기획 확인 후 별도 작업입니다.
