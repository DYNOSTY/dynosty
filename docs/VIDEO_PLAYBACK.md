# 수동 영상 재생

상단 **개발 도구**를 열면 영상 재생 기능을 사용할 수 있습니다. 패널 닫기는 재생 정지가 아니며, 정지 버튼으로 멈춥니다.

화면의 **영상 파일**에서 로컬 파일을 선택하고 **영상 재생**을 누릅니다. 영상은 한 번 재생하며 끝나면 ‘재생 완료’를 표시합니다. **영상 정지**는 재생 위치를 처음으로 돌리고 화면을 비웁니다. 다시 재생하면 같은 파일을 처음부터 사용합니다.

설정의 **전체 음량·소리 끄기**를 영상 소리에도 적용합니다. 영상은 BGM·음성과 독립된 재생 채널이며, 영상 재생·정지·교체가 다른 채널을 자동으로 멈추거나 음량을 줄이지 않습니다. 사건별 자동 재생·게임 일시정지·우선순위는 추가하지 않았습니다.

## 파일과 수명

- 파일은 브라우저 안에서만 사용하며 서버로 업로드하지 않습니다.
- 파일 선택만으로 재생하지 않으며, 새로고침 후 다시 선택해야 합니다. 음량 설정만 기존 로컬 설정에서 복원합니다.
- 새 파일을 선택하면 이전 영상을 중지하고 이전 Object URL을 해제합니다.
- 같은 영상 요소의 오디오 연결을 재사용합니다. 화면 종료 시 재생·파일 참조를 정리하며 공용 오디오 소유자가 출력 연결과 AudioContext를 정리합니다.
- 지원하지 않는 파일 종류는 이전 선택을 유지하고 안내합니다. 손상·미지원 코덱·재생 거부는 안전한 안내를 표시하고 다시 선택하거나 재생할 수 있습니다.
- 정지·교체 뒤 늦게 도착한 이전 재생 응답과 오류는 현재 표시를 바꾸지 않습니다.

`VideoPanel.tsx`는 화면의 HTMLVideoElement를 공용 `audio.ts`에 전달합니다. `video` 채널도 기존 확인음·BGM·음성과 같은 GainNode를 거칩니다. 별도 영상 자체 음량 제어로 전체 음소거를 우회하지 않도록 재생·정지는 외부 버튼으로 제공합니다.

실제 재생 가능 코덱은 브라우저에 따릅니다. 자막 파일 가져오기, 별도 일시정지·탐색·전체화면 조작은 이번 범위에 포함하지 않습니다. 사용자 선택 영상의 자막을 임의로 생성하거나 빈 자막으로 대신하지 않습니다.

## 검증

단위 검사로 외부 영상 요소 연결·재사용·교체·정지와 다른 채널 보존을 확인합니다. 브라우저 검사에서는 직접 만든 소리 포함 WebM의 실제 해상도·디코딩 프레임·재생·정지·자연 종료와 저장된 음량·음소거 적용을 확인합니다. BGM 동시 재생 중 영상 교체·정지, 파일 참조 해제, 손상 파일·주입한 재생 거부와 복구도 검사합니다.

테스트 파일은 `tests/e2e/fixtures/README.md`에 생성 방법을 기록했습니다. 실제 게임 영상의 내용·자막·기기별 코덱·청취 품질은 검증 범위가 아닙니다. 기존 게임 저장과 설정, API·DB·3D 검사는 함께 유지합니다.
