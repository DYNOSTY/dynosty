# 사용자 승인 개발 기준 v1

적용일: 2026-11-17 KST. 사용자가 기존 추천 조합 적용과 나머지 구현 선택을 위임한 개발 기준입니다. Google Drive 원문이나 기획 담당자의 별도 최종 승인본을 수정한 것으로 표시하지 않습니다. 과거 검토 문서 두 개는 원문 그대로 커밋에서 제외합니다.

실행 데이터의 정본은 `packages/game-core/src/game-data.json`입니다. 수치를 화면·Worker에 다시 적지 않고 Core에서 검증한 값을 사용합니다. 누락·음수·중복 ID·잘못된 식성·지원하지 않는 버전은 새 게임/불러오기를 거부합니다.

## 기존 추천 조합 적용

| 항목      | 적용 기준                                                                                                                                                        |
| --------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 3·5단계   | 3단계는 도착 사건, 5단계는 노선 선택 후 최소 10일. 연구 미완료 시 마감 실패로 만들지 않음                                                                        |
| 4단계     | 준비 15일 + 혹한 15일                                                                                                                                            |
| 실패      | 비관 100 또는 낙관 0을 각각 24시간 유지하면 추방. 회복 시 해당 유지 시간 초기화. 비관 90 경고, 단계 시작·합류 인원 대비 80% 사망 실패. 성공과 동시에는 실패 우선 |
| 자원      | 풀·고기·어류·목재·철재·물·석탄, 기존 RES_* 식별값과 대응                                                                                                         |
| 연료      | 온돌·식당 모두 석탄 부족 1당 목재3, 난방 우선·예약 목재 보호. 기준 시설 전량 목재 환산 26.8125/일                                                                |
| 사건·연구 | 4단계 초반 C04, C01~04→R17→R18, 5단계 양녕·노선 선택 이후 R19                                                                                                    |

실패·엔딩 판정은 Core의 순수 함수와 검증 예제를 제공합니다. 현재 등록된 초기 24개 작업에는 5단계 전체 캠페인·연구·정책 UI 구현이 포함돼 있지 않으므로 완성된 전체 캠페인으로 보고하지 않습니다.

## 이번 위임으로 정한 시작·시간·소비 기준

다음 값은 원문에서 발견한 확정 숫자가 아니라, 이번에 위임받아 정한 수정 가능한 개발 기준입니다.

- 시작: 1일 00:00, 주민60명. 성체 트리케라톱스(초식)·벨로키랍토르(육식)·스피노사우루스(어식)를 각20명. 낙관50·비관0·보통 날씨, 대표 온돌 둥지1곳.
- 시작 재고: 풀120·고기120·어류120·목재120·철재40·물180·석탄60. 단위는 게임 재고 단위이며 1/10000 정밀도로 저장합니다.
- 식량: 각 성체1단위/일, 식성별 분리. 다른 식량으로 몰래 대체하지 않습니다. 분 단위 고정 소수 정산의 나머지를 보존해 분할 계산과 하루 계산을 일치시킵니다. 부족분을 음수 재고로 만들지 않습니다.
- 경고: 식성별 하루분 미만 주의, 0은 긴급. 하루분 이상이면 해제합니다. 기아의 체력 피해·자동 사망은 이번 CORE-003/004 재고·경고 작업에 포함하지 않습니다.
- 시간: 현실1초=게임10분, 하루144초. 첫 시작·불러오기·탭 비활성 후에는 일시정지, 다시 시작 버튼을 눌러 재개합니다. 지연 정산은 최대1초, 탭 밖·오프라인 누적 정산은 하지 않습니다.
- `1일 진행`은 자동 시간이 멈춰 있어도 명시적으로 하루를 계산하는 조작입니다. 개발 도구의 식량 고갈/복구는 검사용 명령이고 생산·교역 보상이 아닙니다.
- 엔딩 A의 비관30 이하 유지 기간은 10일을 적용합니다. 단계5 최소10일·단서/연구·노선 조건과 함께 검사합니다.

이동 속도·정책 비용·실제 냉기 피해·BGM 자동 재생처럼 현재 24개 카드에 없는 후속 시스템을 임의로 구현 완료 처리하지 않습니다. 데이터에 있는 사건·연료 기준도 실제 해당 시스템이 모두 구현됐다는 뜻은 아닙니다.

## 3D 개발 기준과 제작물

- 자체 제작한 프리미티브 조합 JSON 모델: `apps/web/public/models/triceratops.json`, `ondol-nest.json`. 외부 모델을 복사하지 않았으며 박찬님의 최종 제작물이라고 표시하지 않습니다.
- 대표 주민은 실제 시작 명단의 첫 R02 주민과 공용 식별값을 연결합니다. 화면에는 주민1종을 대표로 표시하며 주민60명을 모두 그렸다고 주장하지 않습니다.
- 표시1단위=개발 표시1m, 지형20×20, 중앙 배치 구역은 높이0, 가장자리 낮은 구릉. 공룡·건물은 비례화한 개발 아트이며 실제 생물 크기 재현이 아닙니다.
- 중심 배치: 주민(-2,0,1), 건물(0,0,-1). 발·건물 바닥은0에 맞춥니다. 기본 정면은 카메라 쪽입니다.
- 회전·확대 범위: 거리4~48, 극각0.2~1.35rad, 기본 거리12·극각π/3. 시선 이동은 고정해 지형 아래로 타깃을 옮기지 않으며 기본 시점 버튼으로 복귀합니다.
- 대기 호흡과 걷기 다리·꼬리 동작을 한 갱신 루프에서 전환합니다. 실제 이동 경로 계산은 별도 후속 작업입니다. 모델 파일 실패는 안내하고 연결 예제로 대체합니다.

## 저장과 호환

실제 생존 상태는 `dynosty.play.saves`의 최근·직전 기록으로 저장합니다. 주민·건물·재고·시간·정산 나머지·규칙 버전을 검사하고 한 번에 갱신합니다. 쓰기 실패·손상된 기존 기록은 덮어쓰지 않습니다. 기존 `dynosty.example.saves`와 예제 파일 내보내기/가져오기는 별도 연결 확인 기능으로 유지합니다. 예제 시간과 실제 생존 시간은 구분해 표시합니다.

## 변경 방법

기준 변경은 JSON과 검증 예제를 함께 수정하고, 기존 저장 호환에 영향이 있으면 규칙/저장 버전을 올립니다. 사용자 승인 추천 조합, 위임받은 개발 값, 원문 근거를 구분해 이 문서와 데이터의 출처를 갱신합니다.
