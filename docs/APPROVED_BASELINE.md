- 마을 시점은 기본 거리56·극각54도, 거리4~140이며 시선 이동을 지원합니다. 조달 현장은 기본 거리12·극각60도, 거리4~48과 기존 장소별 초점 이동을 유지합니다.
- 정찰은 진행·발견을 보여 주는 시안입니다. 게임 저장에는 포함하지 않고 인원·식량을 차감하지 않습니다. 새 게임이나 성공적인 게임 불러오기에서 정찰 표시도 초기화합니다.
- 소프트웨어 렌더러는 마을의 3D 해상도를 조정하고 대체 지도를 사용합니다. 조달 현장은 원래 해상도를 유지합니다. 하드웨어 렌더러의 미니맵 캡처는 시간 제한을 두며 주 화면 준비를 차단하지 않습니다.

## 저장과 호환

실제 생존 상태는 `dynosty.play.saves`의 최근·직전 기록으로 저장합니다. 주민·건물·재고·시간·정산 나머지·규칙 버전을 검사하고 한 번에 갱신합니다. 쓰기 실패·손상된 기존 기록은 덮어쓰지 않습니다. 기존 `dynosty.example.saves`와 예제 파일 내보내기/가져오기는 별도 연결 확인 기능으로 유지합니다. 예제 시간과 실제 생존 시간은 구분해 표시합니다.

## 변경 방법

기준 변경은 JSON과 검증 예제를 함께 수정하고, 기존 저장 호환에 영향이 있으면 규칙/저장 버전을 올립니다. 사용자 승인 추천 조합, 위임받은 개발 값, 원문 근거를 구분해 이 문서와 데이터의 출처를 갱신합니다.
