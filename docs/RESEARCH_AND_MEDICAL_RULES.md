## 병원: 이동 → 입원 → 회복 → 퇴원

1. 부상 사건이 발생한 주민은 건강 상태가 치료 필요로 바뀌고 생산·건설 등에서 빠진다. 기존 주민과 이벤트로 합류한 주민 모두 같은 규칙이다.
2. 빈 병상이 있는 가까운 병원을 찾아 자동 이동한다. 이동 중에는 회복하지 않는다. 병원이 없거나 병상이 가득 차면 대기한다.
3. 병원에 도착하면 병상을 사용하고 실내로 들어간다. 외부 주민 모델은 숨긴다.
4. 입원해 누워 있는 동안 회복량이 자동 누적된다. 낮·밤과 작업장 운영시간, 야근 지정에 관계없이 회복한다. 현재는 별도 의료 직원·수동 치료 버튼·치료 실패 확률을 요구하지 않는다.
5. 부상 정도에 따라 필요한 총 회복량만 다르다. 회복 속도는 같고, 임계량을 다 채우면 건강 상태가 정상으로 바뀌며 병상을 비우고 자동 퇴원한다.
6. 퇴원한 주민은 일반 주민의 식사·귀가·자동 업무 배정에 다시 합류한다. 사망한 주민은 치료로 되살아나지 않는다. 메카 루트의 사건은 별도다.

병원 클릭 화면에는 해당 병원으로 이동 중이거나 입원 중인 주민, 종, 부상 정도, 회복량/필요량, 진행 막대를 표시한다. 대기 주민 수와 병상 사용량도 보여 준다. 입원 중에도 기존 식성·배급 기준으로 식사하며 별도 추가 배식은 없다.

현재 개발용 정량:

| 항목                       | 값                                                                              |
| -------------------------- | ------------------------------------------------------------------------------- |
| 건설                       | 목재30·철재4, 공사량240 (표준 인력4명 작업 약40초 + 이동·자재 운반)             |
| 기본 병상                  | 5/15/25명 (건물1/2/3단계)                                                       |
| 경상/부상/중상 필요 회복량 | 720/1440/2880                                                                   |
| 회복 속도                  | 건물1/2/3단계에서 게임1분당1/1.5/3                                              |
| 체감 시간                  | 1배속에서 입원 후 경상은 게임12/8/4시간, 부상2배·중상4배. 이동·병상 대기는 별도 |

자연 질병·사망 확률은 계속 보류한다. 사건이 경중을 지정하면 그대로 적용하고, 경중이 없는 기존 부상/치료 필요 저장은 경상으로 이어간다. 별도의 무작위 중상 판정은 만들지 않는다. 진행량·경중·병원 배정을 저장하고 사망·외부 회복 사건 시 병상을 반납한다.

## 공통 연구 묶음

연구는 기술 공방에서 한 번에 한 건 진행한다. 인원 배치와 현장 도착이 필요하다. 연구 완료는 개량을 **허용**하며 건물을 즉시 자동 개량하지 않는다. 개량 지시는 플레이어가 내리고 자재·공사·유휴 인력을 사용한다.

### 건물별 단계 연구

각 건물의 기본 1단계는 건설 가능 상태이며, 해당 종류의 2단계 연구 → 2단계 개량, 이어서 3단계 연구 → 3단계 개량 순서다. 한 종류의 연구가 모든 건물 종류를 함께 올리지 않는다.

| 종류           | 연구 대상과 범위                                                                   |
| -------------- | ---------------------------------------------------------------------------------- |
| 거주·생활      | 온돌 둥지, 공동 식당, 병원 각각 2·3단계 개량 허가                                  |
| 자원·식량 생산 | 제재소, 석탄광, 철광산, 채석장, 어획막, 온상 재배소, 목축장 각각 2·3단계 개량 허가 |
| 지원 시설      | 공동 저장소, 기술 공방, 정찰 거점, 교역소 각각 2·3단계 개량 허가                   |

기본 단계·개량 비용·연구 비용은 서로 별도다. 생활·지원 시설은 전용 효과를 쓴다. 병상·회복은 C1 확정값, 둥지 공간20/30/40·식당 좌석4/6/8·공방 연구 속도1/1.5/2배·정찰/교역 현지 처리1/1.5/2배는 개발용이다. 이동 속도와 생산 배율을 생활 시설에 무차별 적용하지 않는다.

### 자원별 생산·채집 연구

목재, 석탄, 철광석, 석재, 풀, 고기, 어류를 각각 독립된 연구 계열로 둔다. 1단계는 해당 자원의 기본 처리량 1.5배, 2단계는 2배이며 선행 1단계를 요구한다. 물·철재처럼 아직 실제 생산시설이 없는 품목은 생산시설 설계와 함께 연결한다.

가축 번식과 작물 성장은 개체 단위로 만들지 않고, 해당 생산 건물의 품목 산출량으로 정산한다. 자원 연구가 운반·하역을 생략하거나 재고를 즉시 지급하지 않는다. 유한한 숲·광맥·암반에서 채집하면 실제 잔량도 줄어든다.

최종 일반 생산 배율은 **건물 단계 배율과 자원 연구 배율 중 높은 값**, 최대2배다. 예: 건물2단계1.5배 + 채집2단계2배 → 최종2배. 두 항목이 모두 최고여도4배가 되지 않는다. 기존 계단식 온상 보정도 최종2배 상한을 넘지 않는다.

### 저장소 공간 연구

저장소1/2/3단계는 품목별500/1000/2000이다. 저장 공간 연구1/2는 각 저장소의 공간을 최소1000/2000으로 올린다. 건물 단계와 공간 연구 중 큰 용량만 적용하며 서로 곱하지 않는다. 저장소가 여러 곳이면 합산하고, 이전 고정 저장소도1단계로 합산한다. 별도 저장소가 없는 시작 마을에는 공동 적재500을 유지한다. 실제 저장소를 지으면 그 용량 합계를 쓰며 시작 적재500을 중복 가산하지 않는다.

공유 재고 체계는 유지한다. 재고는 품목별 한도이며 공간 연구가 자원을 생산하지 않는다. 창고 용량을 넘긴 화물은 야적장에 내린다. 이후 창고가 늘어나면 새로 확보한 용량만큼 야적 재고가 창고에 들어간다. 야적 중인 식량은 하루가 지나면 품목별로 1개씩 상한다.

### 정찰 이동 연구

| 단계                              | 효과                   | 중첩                             |
| --------------------------------- | ---------------------- | -------------------------------- |
| 기본                              | 정찰 기본 이동속도 1배 | 기준                             |
| 이동 개선1 (기존 길 표식 ID 유지) | +50%, 1.5배            | 기본을 대체                      |
| 이동 개선2                        | +100%, 2배             | 개선1을 대체. 1.5×2 아님         |
| 날틀                              | 기본의 10배            | 공통 속도 연구를 대체. 2×10 아님 |

교역 배송에는 정찰 전용 속도를 적용하지 않는다. 기존 나르미 ×1.25는 별도 스킬로 남긴다. 날틀의 ‘기본10배’에는 이 스킬을 추가로 곱하지 않는다. 정확한 스킬 중첩은 후반 기술 구현 때 이 기준을 따른다.

## 최후반 세 루트

아래는 단순히 교역망3단계가 되면 열리는 공통 연구가 아니다. 이야기 사건과 루트가 충족되어야 한다. 서로 다른 조건을 동시에 만족한 것처럼 처리하지 않는다.

| ---------- | -------------------------------------------------------------------------------------------- | ------------------------------------------------------- | --------------------------------------------------------------------------- |
| 날틀       | 양녕의 반란을 진압하는 루트                                                                  | 정찰대 이동속도 기본10배                                | 양녕 독재 선택이나 교역 횟수만으로 해금하지 않음                            |

메카 노동 개체는 원래 사망 주민과 구별해 기록하고 뼈의 출처를 추적한다. 같은 사망자의 뼈를 반복 사용해 노동 개체를 무한 생성하지 않는다. 현재는 사망 주민1명의 뼈로 메카 노동 개체1명을 등록한다. 원래 사망 기록은 유지하고 뼈는 한 번만 쓴다. 별도 제작 재료·정비·연료는 추가하지 않았다. 메카는 기존 자동 일손 배정에 합류하며 배치된 생산·연구·공사에서 야간에도 일할 수 있다. 체격별 작업력은 기존 규칙을 따른다.

전기자극기의2배도 최종 기본 대비 값으로 기록한다. 최고 시설2배에 다시 곱해4배로 만들지 않는다. 적용 시설·시행 방식·불이익의 세부 값은 미정이며 새 부상·사망 확률을 임의로 추가하지 않는다.

구 마스터의 R17 유산 기록 대조·R18 의식 이전 장치·R19 탈출 기관은 삭제하거나 ID를 다른 기술에 재사용하지 않는다. 날틀과 R19의 동일 기술 여부, 상세 단서·연구 선행·최종 엔딩 연결은 본편 미션 수정 때 이 세 루트에 맞춰 대조한다.

후반 사건은 일반 교역 횟수로 만들어내지 않는다. 본편 스크립트가 아래 사건을 전달하면 같은 계산 규칙이 동작한다. 개발 도구의 ‘후반 사건 전달 검사’도 이 명령을 사용한다.

- story-event / rebellion-started: 양녕의 반란 시작.
- rebellion-suppressed: 날틀 노선 확정.
- chungnyeong-assassinated: 충녕 사망·메카 노선 확정.
- allied-yangnyeong: 양녕 협력·독재 노선 확정.
- TECH_MECHA2 연구 완료: 충녕의 상태를 기계 부활로 전환.
- mechanize: 사망 주민을 출처로 노동 개체 등록. 살아 있는 주민이나 이미 사용한 뼈는 불가.
- electrical-work: 연구 완료 후 지정 생산시설의 강제 작업 시행/해제.

분기를 확정한 뒤 다른 분기를 선택하지 못하며, 선행·노선이 다른 후반 기술은 연구할 수 없다. 전체 본편 엔딩 달성을 대신하지 않는다.

## 좌하단 인물 대사

평소에는 낮에 나르미가 물자와 조작을, 밤에 달이가 주민 생활을 안내한다. 연구가 한 건 끝날 때마다 영실이 연구명을 들어 고리에게 보고한다. 충녕과 양녕은 각자의 미션에서, 반란의 파키케팔로사우루스는 해당 사건에서만 이 자리에 잠깐 등장한다. 대사가 끝나면 그때의 낮·밤 길잡이로 돌아간다.
