# 불량품 교환·재납품·재검수 체험

**마른 목재20 조달 체험하기 → 일손 배치·배급 체험하기**에서 시작합니다. A를 약정하고 운송·검사 후 정상16을 수령하면 격리4의 **현장 보완 / 공급처 교환**을 선택합니다. 기존 시나리오·영상·생존 및 고전 목재 예제는 유지합니다.

## 두 처리 방식

| 방식           | 철재와 담당                                | 예상 결과:8시간에 시작하고 배급에 남는 일손을 모두 배치 |
| -------------- | ------------------------------------------ | ------------------------------------------------------- |
| 현장 보완      | 추가 철재0,2명으로 활성4시간               | 목재12시간 완료·배급11시간 완료·철재4 남음              |
| 공급처 교환    | 추가 철재1, 담당1명, 왕복3시간+재검수2시간 | 목재13시간 완료(60분 지연)·배급10시간 완료·철재3 남음   |
| 처음부터 공급B | 원래 제안 비용6, 최초 운송·검사 담당1명    | 목재12시간·배급10시간 완료·철재2 남음                   |

위 조건은 체험 비교를 위한 개발값이며 최종 기획 확정값이 아닙니다. 보완은 목재 기한에, 교환은 배급에 쓸 일손 확보에 유리하도록 차이를 둡니다. 실제 선택·출발·검수·수령·일손 배치가 늦으면 위 결과도 달라집니다.

## 교환 플레이 순서

1. 정상16을 먼저 배분할 수 있습니다. **불량4 교환 요청**은 빈 일손1명과 추가 철재1을 예약합니다. 격리4는 아직 현장에 있습니다.
2. **교환 요청 취소**는 출발 전에만 가능합니다. 결제 없이 철재·담당 예약만 해제하며 현장 보완으로 돌아갈 수 있습니다.
3. **교환 회수 수레 출발**에서 철재1을 지불합니다. 불량4가 회수 중 물량으로 이동하며 출발 후 취소·환급은 없습니다. 담당자는 재검수 완료까지 예약됩니다.
4. 회수90분 뒤 공급처에서 정상 교환품4를 보내며 재납품90분 뒤 도착합니다. 수레의 푸른 물량은 회수품, 노란 물량은 교환품입니다. 도착품은 검사대기로 이동하고 바로 사용할 수 없습니다.
5. **교환품4 재검수 시작**을 누르면 담당1명으로120분 검사합니다. 검사대 위 물량이 합격 색상으로 바뀌고 담당자는 대기로 복귀합니다. 아직 사용 가능 재고는 증가하지 않습니다.
6. **재검수 합격4 수령 확인**에서만 사용 가능 목재에4가 추가됩니다. 남은 목재를 배분하고 **확장 목재 사용 확인**으로 지붕 보수를 마칩니다.

교환 담당1명 외의 일손은 배급에 배치하거나 재배치할 수 있습니다. 회수·재납품·배급 완료·재검수 중 가장 이른 사건에서 공용 시간이 멈춥니다. 보완을 이미 진행한 물량은 교환으로 중복 처리하지 못합니다. 보완 진행이0인 채 담당만 배정했다면 해당 담당을 모두 대기로 옮겨 교환을 선택할 수 있습니다.

## 재고·비용 보존

검사대기·수령전·격리·교환운송·사용가능·배분·사용확인의 물량을 합산합니다. 최초 납품 후에는 총20을 유지하며 교환4는 하나의 단계에만 표시합니다. 회수한 불량과 교환품을 동시에 사용 가능한 재고로 더하지 않습니다. 추가 철재는 요청 시 예약, 출발 시 한 번 결제하며 같은 명령 반복·다른 식별값의 재출발·재검수·재수령도 중복 처리하지 않습니다.

기본 목재 원장의 미해결4는 교환 상태가 물리적 위치로 투영합니다. 교환 완료 전에는 이4를 계속 사용 불가로 보유하고, 명시 수령에서 원장의 격리4를 사용 가능4로 한 번 옮깁니다. 물량을 별도 원장에 복사해 합산하지 않습니다. 기본 약정 비용과 교환 추가 비용도 분리해 검증합니다. 이 투영은 화면 표시용이며 기본 목재 계산·저장 파서에 다시 입력하지 않습니다.

## 저장 호환과 복원

일손 저장은 `dynosty-labor`의 저장 버전2·상태 버전2를 사용하고 기존 `dynosty.labor.saves`의 최근/이전 보관 구조는 유지합니다. 기존 v1 저장은 읽을 때 교환 없음으로 호환하고 보완 진행량·일손 배치·시간을 보존합니다. 불러오기만으로 원문을 쓰거나 자동 덮어쓰지 않으며, 저장 버튼을 눌렀을 때 v2로 저장합니다. v1 형식에 알 수 없는 교환 정보가 들어 있거나 현재/이전 저장 중 하나가 손상되면 쓰기를 거부하고 원문을 유지합니다.

교환 요청·회수·재납품·재검수·수령 대기·완료 저장 모두 담당자·예약/지불·물량 위치·시작 시각을 보존합니다. 새로고침 후 불러오면 일시정지 상태이며 남은 시간부터 진행하고 추가 비용을 다시 내지 않습니다. 출발·검수 시작 시각으로 종료 시각을 재계산하며 누락·미래·단계와 불일치하는 시각, 중복 물량과 담당 예약 불일치를 거부합니다. 기존 목재·생존 저장 키는 변경하지 않습니다.

## 개발값과 본편 미정

추가 철재1·담당1명·회수90분·재납품90분·재검수120분·정상 교환품4 고정은 **이번 체험 전용 개발값**입니다. 기존 목재20, 공급A/B, 일손4명, 배급 요청과 현장 보완 수치는 그대로 재사용합니다. 실제 공급처의 반품 책임·위약금·보증·공급 신뢰도·무작위 불량률, 본편 영양·기아·사망·사건별 영상 조건은 미정이며 이번 작업에서 계산하지 않습니다.

화면 이동은 기존과 같이 표시용 보간입니다. 구현 검증과 실제 사용자 재미·난이도·실기기 성능 평가는 구분합니다.

저장 형식의 기존 시간 범위를 넘어 끝나는 교환 요청·출발·재검수는 진행이나 비용을 바꾸지 않고 거부합니다. 예약 후 너무 오래 출발하지 않았더라도 출발 전 취소로 예약을 해제할 수 있습니다. 범위 밖에서 종료되는 교환 저장도 원문을 유지하며 거부하고, 시간 상한 정각에 완료하는 정상 교환은 수령·배분·사용까지 허용합니다.
