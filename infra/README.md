# 서버와 운영 환경

지금 준비된 것은 **개발 PC에서 PostgreSQL을 실행하는 설정**입니다.
API와 Web은 Node.js 개발 명령으로 실행합니다.

루트에서 `pnpm run setup` → `pnpm db:up` → `pnpm db:check` 순서로 실행하세요.
DB는 개발 PC 안에서만 접속할 수 있고, 프로젝트 전용 Docker 볼륨에 데이터를 보관합니다.
`pnpm db:down`은 컨테이너를 중지·제거하지만 데이터를 담은 볼륨은 보존합니다.

운영용 HTTPS·도메인·배포·백업·복구 구성은 아직 구현하지 않았습니다.
Hostinger KVM 2는 후보이며, 이 설정을 운영 서버에 그대로 적용하지 않습니다.
개발용 DB는 컨테이너당 메모리를 제한했습니다. 실제 게임의 서버 수용량을 뜻하지 않습니다.
